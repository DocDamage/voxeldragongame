## Rules for every regional child

Each packet must name required capabilities, optional shortcuts, a humanoid
return path, compact-dragon clearance, true-form arenas, travel conditions,
one-time rewards, and save recovery. It must use supplied real art, preserve
Mutable as creator, GAS as combat authority, existing dragon/control owners,
and `UWyrmSaveSubsystem` as the sole persistence coordinator. Optional Echoes
must not become a hidden completion tax. Missing content blocks only that child.

Select and execute one eligible child at a time. WP-23.0 verified all ten source
dragon models but only two production-ready rig identities. WP-23.2 closed
Jade Peaks with its verified Jadefang identity and supplied ruler art; WP-23.1
then closed Verdant Reach on the existing Verdance/Region 01 baseline. Story
order alone does not authorize parallel production.

## Boundary

The umbrella authorizes planning and eventual production of the complete
rest-of-world campaign. It does not certify that missing dragon rigs, regional
art, characters, animation, audio, or traversal content exist. WP-22 is now a
verified bounded baseline; it is not the full Jade Peaks campaign closure.
