# WP-03 — Shared Humanoid Control, Camera & Input Foundation

**Dependency:** WP-01 (Terrain Provider Proof) and WP-02 (Playable Mutable Character Recipe).
**Scope:** Shared humanoid control, camera continuity, direct and click movement, input context/mode gating, camera persistence.

Read [Technical Architecture](../../DesignPack/docs/TECHNICAL_ARCHITECTURE.md), [Save and Control Contract](../../DesignPack/docs/systems/SAVE_AND_CONTROL_CONTRACT.md), [UI UX Controls](../../DesignPack/docs/UI_UX_CONTROLS.md), and [Acceptance Tests](../../DesignPack/docs/production/ACCEPTANCE_TESTS.md).

## Objectives

1. **Shared Humanoid & Control:**
   - The same `AWyrmCharacter` humanoid actor supports both third-person direct WASD/gamepad movement and top-down click-to-move navigation.
   - Direct movement input (WASD / analog stick) cancels any active click-to-move path immediately (`WRLD-06`).
   - Movement respect pause, hit-stun, interaction locks, and menu focus states (`UI-02`, `UI-07`).
   - No duplicate pawn or progression instances.

2. **Camera Continuity & Perspective Switching (`UI-03`):**
   - Seamless runtime switching between third-person follow camera and top-down tactical/isometric camera on the same humanoid actor.
   - Preserve framing, active character state, and ground targeting fidelity across camera transitions.
   - Camera preference persistence (`SAVE-05` / `UI-03`).

3. **Input Context & Device Neutrality (`UI-01`, `UI-02`):**
   - Input chord/context consumption: chord releases, menu toggles, and mode switches cleanly release or consume input without stuck actions or accidental attacks/jumps.
   - Mouse/keyboard and gamepad device parity.

4. **Acceptance Proof:**
   - Native automation tests for camera state transitions, click-to-move cancellation upon direct input, and pause/interaction input gating.
   - Headless PIE proof verifying smooth camera switching, click-to-move execution and cancellation, and camera preference persistence.
