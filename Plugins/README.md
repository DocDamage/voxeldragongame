# External plugin staging

Required engine plugins are enabled in WYRMFALL.uproject; their binaries are NOT bundled here. Mutable's descriptor name is `Mutable`, not `CustomizableObject`. The latter is a runtime module to depend on when WP-02 consumes its verified APIs.

No third-party terrain/water/inventory/building plugin has been selected or installed. Inspect version, license, supported engine and owner conflicts before staging a chosen plugin. Do not enable all available products or redistribute paid files. The doctor reports duplicate/missing descriptors instead of silently choosing.
