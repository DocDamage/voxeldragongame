# Content-specific rules

Root AGENTS.md applies. No production art is bundled. Never manufacture text/JSON files with `.uasset` or `.umap` extensions. Generate/import/save Unreal packages only through Unreal. Preserve paid asset provenance and original reference/mount paths. Use supplied art, not replacement generated characters/icons/audio. Basic Shapes in Development are diagnostic fixtures only.

The bootstrap map script loads an existing map unchanged; preserve authored work. Content folder README files reserve integration locations and explain task gates, not actual playable assets. Do not move vendor assets into these folders without reference-aware migration and a concrete reason.
